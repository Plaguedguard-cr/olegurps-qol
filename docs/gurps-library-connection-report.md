строгое чтение BooksCodex, запрет любых изменений и создания файлов в ней,
полный запрет операций с `E:\НРИ\GURPS\Книги`, приоритет книг над прежними
отчётами, проверка редакции/исправлений, ссылки на название и печатную страницу,
проверка доступности и запрет выдумывать сведения. Книги нельзя копировать в проект,
Git или публиковать; временные извлечения допустимы только вне библиотеки и репозитория.

Прежние инструкции сохранены. Устаревшее указание рабочего источника заменено
на BooksCodex; в отчёте реорганизации уточнён исторический статус архивной копии.
PDF, архивы и остальные материалы не удалялись и не перемещались.
