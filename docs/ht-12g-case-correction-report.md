# 12G 2.75": исправление конструкции гильзы и +P

Исправлена ошибочная интерпретация legacy `heavy_load`. Использованы предоставленные пользователем проверенные данные HT176–177: index159 — 0.11 lb / $0.50 / [3,4], где [3] означает Light Cased (HT164), [4] — Shotshell (HT173); index160 — 0.13 lb / $0.70 / [4], обычная гильза. Ни одна исходная строка не обозначает +P. Книги недоступны; самостоятельная повторная сверка страниц не заявляется.

## Изменение

`scripts/ht-shotshell-source-data.js` хранит явные подтверждённые конструкции, исходные индексы, ID записей, массу, стоимость, примечания и источник. Подтверждение проверяет точные поля записи; не выводит мощность из legacy ID, массы или цены. Слой HT evidence использует эти данные вместо ошибочного признака усиленного заряда. Несовпадение проверенной строки остаётся неполным с адресной причиной `plus-p-case-construction-unverified`.

Исходные HT и Weapon Reference, обе физические identity, ссылки, базовые цены/массы и исторические аудиты не изменены. Новая каталожная errata не потребовалась. Сохраняется ранее утверждённая FN BAR revision 1; старые и новые preservation hashes продолжают проверяться. Добавлены названия RU/EN «облегчённая гильза» / «обычная гильза», Light Cased / Conventional Cased. Новое отображаемое имя не меняет ключи ресурсов или fingerprint рецепта; сохранённые имена, рецепты и снимки не переписываются.

Используется существующий HT165/166 pipeline: Damage ×1.1 с преобразованием кубиков, обе дальности ×1.1, ST ×1.1 с половиной вверх и сохранением суффикса, цена ×1.5. Масса не пересчитывается, Light Cased повторно не начисляется. Получаются $0.75 / $1.05 из собственных исходных цен двух записей. Давление и масса пороха не выдумываются. Safety остаётся undetermined, Malf/RoF — решением GM, индивидуальный допуск и отзыв сохранены.

Для Condor HT91/199 добавлены декларативные подтверждения исходных shot/slug режимов в общем определении типа снаряда. Shot использует собственный `1d pi`, +P `1d pi`, `1x9`, Rcl1; slug — собственный `4d pi+`, +P `4d+1 pi+`, RoF1, Rcl10. Slug не получает дробины. Это подтверждение исходного режима, не универсальный допуск отдельного `ht_rifled_slug`, который остаётся undetermined. TA и общий механизм Shotgun не переписаны.
