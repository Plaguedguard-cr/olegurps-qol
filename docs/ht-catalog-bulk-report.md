Метаданные исходного Bulk и способности приклада сохраняются в снимке; положение приклада не выдумывается, Acc/Rcl и другие поправки сложенного приклада не назначаются.
- Полная дальность восстановила также уже поддерживаемые APDS и SAPFSDS для этого FN: `2400/9900`. Их исходные правила и формулы не переписаны.

Это аудит исходных каталожных пар предыдущего отчёта, **не аудит данных 227 существующих Actor.system**. Вычисление отдельно от допуска. Перебраны только 511 пар +P: после исправления FN доступны 284, остальные 227 совпадают с прежними отказами `unconfirmed-compatibility`. Все 511 каталожных статусов +P остаются `undetermined`; массового допуска или изменения eligibility нет. Предыдущий общий JSON сохранён как исторический результат.

Основная категория выбирается по следующему порядку: доказанный иной принцип действия → недостаточно подтверждения платформы → обязательные отсутствующие числа у подтверждённого класса → ограничение движка → избыточная ветка подтверждения → одно оставшееся решение GM. **Устранимость:** 106 сочетаний B уже можно численно обработать существующим преобразователем после адресного исправления/подтверждения evidence. Это кандидаты на следующий этап, не 106 вновь разрешённых сочетаний. У 61 дополнительно блокируется текущая автономная готовность (59 составных Rcl и 2 отсутствующих Acc), у 27 требуется подтверждение проверки снаряжения powder-and-shot. Эти ограничения перечислены отдельно в каждой строке. Ни одно из 227 сейчас не устраняется одной существующей кнопкой GM approval.

В 153 строках возможно поддерживаемое численное преобразование Damage/Range/ST, но это число включает неподтверждённые платформы и уже имеющиеся бронеделители; оно не означает игровую готовность. В остальных случаях JSON различает неподдерживаемую исходную формулу, область определения HT166-конверсии и неполный Range. Ни одна отсутствующая физическая величина давления не объявлена обязательным численным входом.

**Шесть отдельных неполных Range:** Gyrojet `WhGAE0Z1tyyGl34FX` — `1,000` (F); электрические `Wd25u9Begix9h_smN`, `WsRdm1ykv3AFJUMGr`, `WhZTKRbxWw3dUNLFi`, `W5gRSZbBIrYN9XoUY`, `WBUF21Cjj4FcgwAM2` — `7/5/7/7/5` соответственно (E). Эти значения не исправлялись без источника. Отсутствие второй дальности у иной системы не объявляется ошибкой каталога само по себе.

**Pressure gate:** `weapon_pressure_rating_verified` — доказательство безопасности платформы, не численное давление. `prepareSpecial` уже допускает неизвестное подтверждение давления для полного профиля через политику мира/GM. В каждом из 227 отказов дополнительно неизвестен `availabilityTL` (`min_tl`), в 108 — подходящий `munition_classes_any`. Общий +P `min_tl=4` есть в каталоге; его факты заполняются лишь после более узкого gate обычных кинетических семейств. Для B этот gate избыточен для арифметики HT165. Изменять его или допускать F без проверки платформы в этом этапе не стали.

Всего 31 строка требует отдельной проверки Armoury (Small Arms) / IQ-based Guns−2 перед снаряжением. Неизвестные Malf, качество и RoF — отдельные решения GM, не причины отсутствия арифметики Damage/Range/ST. Неизвестное качество не превращается в Cheap, исходная RoF сохраняется до индивидуального решения. Допуск GM не меняет официальную совместимость.
