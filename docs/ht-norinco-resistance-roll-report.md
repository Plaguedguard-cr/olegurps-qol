## Кнопка и результат

У успешной подготовленной атаки появляется «Бросок HT−5» или «Бросок HT−10».
Промах и обычный Damage такую кнопку не получают. Render-хуки дополняют карточку
одним элементом; исходный HTML GGA для добавления кнопки не переписывается.
Нативные Apply Damage и dkb не затрагиваются.

При нажатии требуется ровно один **выделенный** Token. Target и сохранённая цель
атаки не читаются. GM может выбрать любой токен; PLAYER должен владеть Actor
и иметь право управлять токеном. Значение характеристики читается из текущего
`Actor.system.attributes.*.value`, затем права и выбор повторно проверяются
после диалога. Кнопка не содержит привязки к Actor или Token цели.

Диалог требует явно указать взгляд, дистанцию, Protected Vision и уровень
Nictitating Membrane. Поля изначально пусты: отсутствие защиты не предполагается.
По HT181 за пределами ½D прибавляется +3, Protected Vision даёт +5,
Nictitating Membrane — +1 за уровень; DR не помогает. Для антилазерных очков
HT71 нужно указать оба свойства, включая Nictitating Membrane 4. Если персонаж
не смотрит в сторону лазера, броска и сообщения нет.

Проверка выполняется нативным `doRoll` GGA, 3d6. Modifier Bucket учитывается
самой GGA один раз. После отмены и завершения убирается только временная
поправка этой операции, если она осталась в Bucket; ручные модификаторы сохраняются.
Критические флаги берутся из структурированного результата GGA. Учтён отдельный
дефект GGA 0.18.23: при итоговой HT ≤ 0 она пропускает критический провал на 10+.
Описание модуля дополняет этот случай по B348, сохраняя нативные кубики и карточку.
Критический успех на 3–4 имеет приоритет и при низкой итоговой характеристике.

QXJ04 при провале сообщает временную слепоту на число минут, равное степени
провала. При автоматическом провале 17–18 без положительной степени провала
модуль сообщает о необходимости определить длительность вручную, не выдумывает
положительное число минут. ZM87 сообщает калечащую слепоту и отдельную проверку
HT по B422 в конце боя: успех — временная, провал — длительная, критический
провал — постоянная. Срок длительного повреждения и лечение определяются вручную.
Первичный провал сопротивления не подменяет отдельную проверку длительности.

В сообщение GGA добавляются русское описание последствий и закрытая секция
с именем эффекта, текущей характеристикой, поправками, итогом, кубиками и степенью
успеха/провала. Повторное нажатие выполняет новый бросок сопротивления.
Actor, Token, эффекты, состояния и ресурсы оружия при этом не изменяются.

По дополнительному решению пользователя атаки NORINCO и результаты сопротивления
общедоступны (`whisper: []`, `blind: false`), в том числе сопротивление из старой
приватной карточки. Для новых настроек сообщений AmmoService значение по умолчанию
также «всем». Уже сохранённый выбор «только себе» для сообщений об операциях
с ресурсами сохранён; глобальный режим бросков Foundry не менялся.

История использует сохранённый структурированный контракт эффекта, без извлечения
чисел из HTML и без пересчёта по текущему каталогу. Поддержан прежний snapshot
с явным `resistanceApplicable`; без достоверных данных кнопка не добавляется.
Контракт характеристика → модификатор → условие → GGA → описание допускает
другие характеристики, но содержит только два реализованных последствия.
UT Dazzler и Electrolaser не реализованы.

## Уточнение: батарея при добавлении и режим «Огонь»

По последующему запросу пользователя новый экземпляр каждого NORINCO сразу
получает полный заряд. Изменены `standalone-weapon-service.js`,
`fire-preparation-app.js` и адресные проверки NORINCO. Открытие, редактирование
и reload существующего экземпляра не пополняют батарею; старое отсутствующее
состояние питания также не заменяется автоматически.

Из режима «Огонь» удалён показанный блок из трёх строк об оптике и сопротивлении.
Описание правил и обязательные условия в диалоге сопротивления сохранены.
Остальные предупреждения Fire Control сохраняются.
