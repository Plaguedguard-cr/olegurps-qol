## Первичный источник

Рабочая книга: **GURPS High-Tech, 4e**, из
`E:\НРИ\GURPS\BooksCodex\GURPS - 4E - High Tech.pdf`.
Источник проверен доступным и прочитан только для чтения. SHA-256:
`d791a73bbbad780bf3a337a9a428829d8c7c0a34a9b89f3a47743e991d537260`.
Сопоставлены печатные номера и PDF: HT91 = PDF92, HT94 = PDF95,
HT120 = PDF121, HT137 = PDF138, HT165 = PDF166. Для проверенных страниц
этого файла печатная N соответствует PDF N+1. Книга в проект не копировалась.

HT165 разрешает усиленный заряд для большинства составных и фиксированных
боеприпасов; нетипичные варианты используют ручное изготовление. Для
powder-and-shot необходима проверка безопасного заряжания. Возможные Malf
и RoF автоматического оружия остаются отдельными ручными условиями.
Это не опубликованное подтверждение давления конкретного оружия.
Численные множители и округления HT165–166 не изменялись. Отмена обязательного
GM-допуска — принятое пользователем правило модуля, а не новое утверждение книги.

### Derringer Acc

Проверен **American Derringer Model 1, .410-gauge 3"**, режим
`W7i4ZauQl8q2o5nTt`. HT91 описывает его как вариант почти идентичного
Remington Model 95; таблица того же HT91 задаёт базовый Acc 0, а перечень
изменённых параметров .410-варианта Acc не меняет.

Сырой каталог сохраняет `accuracy:null`. Действующий слой поправок даёт
`{version:1,source:"HT91",fields:[{field:"accuracy",original:null,value:"0"}]}`.
Рабочий профиль и resolver получают Acc `"0"`. Все три уровня проверены
отдельно. При этом +P для этого режима остаётся заблокированным:
дискретное преобразование HT166 для `1d-3` не сохраняет исходное распределение
при обратной нормализации. Причина `plus-p-low-damage-roundtrip-unverified`
и проверки всех граней кубика сохранены.

## Реальная ошибка диагностики G

После исправления списка обнаружена ошибка `auditPlusPCategoryG`:
`potentialAfterAllRequiredGMDecisions` складывал **368 + 27 + 3 = 398**.
Из трёх legacy individualGMRequired строк APS/KPV уже входят в 368;
добавлять их повторно нельзя. Это ошибка отчётного read-only подсчёта,
а не реальная несовместимость оружия или ошибка Damage.

Предложенное и реализованное решение: в последнем слагаемом учитывать
только строки `!worldPolicyReady && nativeGGAProfileSafeAfterGM`.
Остаётся только LeMat: **368 + 27 + 1 = 396 уникальных готовых после
необходимых ручных проверок пар**. Тест закрепляет точное пересечение
APS/KPV, точную остающуюся пару LeMat и сумму. Ожидание 396 не заменено на 398.
Другие поля и legacy-имена отчётного контракта сохранены. Они не вводят
GM-права и не используются как игровой допуск. Исторические flags/provenance
с именем individualGMRequired не удалялись и не переписывались.
