# APEX/APHEX: взрыв, осколки и штатный Damage

Проверка: 10 октября 2026, Foundry VTT 14.364, GGA 0.18.23.

## Совместимость и разрешение GM

HT APHEX больше не получает запрет только из-за платформы rifle. Описание преимущественного применения в HMG/autocannon не рассматривается как исчерпывающий список разрешённых платформ. Остальные проверки HT и отдельные ограничения UT сохранены. Для подтверждённого АК-47 базовый 7.62x39mm совместим, APEX/APHEX без дополнительных оснований остаются `undetermined`. Исторический вывод о запрете rifle в отчёте предыдущего этапа больше не применяется.

Разрешение GM хранится в настройке мира `olegurps-qol.ammunitionApprovals`. Его область: Actor, конкретное оружие, подтверждённый каталожный режим и патрон, вариант конструкции, отдельный ID рецепта и отпечаток его параметров. Оно не меняет каталожный результат на `compatible`, не переносится на другое оружие и не обходит достоверный запрет. Игрок не может выдать разрешение. GM может отменить его в редакторе рецепта.

В существующем окне снаряжения добавлен сворачиваемый редактор с параметрами, происхождением значений, калибровкой, предварительным расчётом и статусом полноты. Интерфейс различает подтверждение справочником, разрешение GM, неизвестную совместимость и достоверную несовместимость. Изменённые параметры сохраняются как новый рецепт с новым стабильным ID и отдельным запасом. Прежние запасы, магазины и снимки не переписываются. Неполный или более не разрешённый взрывной рецепт блокируется до штатного броска и списания боеприпаса.

## Расчёт

- Взрыв: `D_ex = 12 * sqrt((M_ex * REF) / 453.59237)`, масса ВВ в граммах, результат в d6. Для APEX масса ВВ строго меньше 5% массы снаряда. Для APHEX процент не назначается.
- Осколки: `D_frag = D_ref * sqrt((M_frag / M_ref) * Q)`. Это домашняя модель OleGURPS, версия `olegurps-fragments-v1`, для одного осколочного попадания. Масса материала, опорная масса, опорный урон и источник калибровки вводятся явно. `Q = 1` подписан как нейтральное допущение.
- Для дробных кубиков используется общий с существующим расчётом падения механизм Basic B371/B470: до 0.25d — `1d-3`, до 0.5d — `1d-2`, оставшаяся часть до 1d — `1d-1`; от 1d округление до целого кубика, половина вверх. Преобразование кинетики AP остаётся прежним, по HT166.
- Отсутствующие значения дают `unresolved` с причинами и формулами `null`; неизвестная масса не становится нулём. Проверяются положительность, конечность, физические ограничения масс и калибровки. Необычно большие параметры или результат сопровождаются предупреждением, без скрытого ограничения.
- Версия, входные значения, источник, результаты и журнал преобразований входят в неизменяемый профиль выстрела. Сохраняются проверки уже имеющихся нативных делителей, Linked/Follow-Up и ранее применённых преобразований.

Источники: [High-Tech, HT169–170](https://gametable.pbworks.com/f/GURPS%2B-%2B4th%2BEdition%2B-%2BHigh-Tech.pdf), Basic Set B415; [текст Basic Set B470](https://anyflip.com/zupby/pxnl/basic/451-500). Формула фрагментации является согласованной домашней моделью, а не правилом этих книг.

## Условный пример АК-47

Это параметры временной проверки, а не официальная номенклатура патронов. Исходный урон GGA: `5d+1 pi`. Масса снаряда 8 г; REF 1.4; материал фрагментации 6 г; опорный урон 2d; опорная масса 146 г; Q 1. Источник — явное условное решение GM. Оценка 146 г отмечена как предварительная калибровка M406 и не считается измеренной массой осколков.

| Конструкция | Масса ВВ | Кинетика | Взрыв до округления | Штатная формула взрыва | Один осколок |
| --- | ---: | --- | ---: | --- | --- |
| APEX | 0.3 г | `4d-1(2) pi-` | 0.365151 d6 | `1d-2 cr ex` | `1d-2 cut` |
| APHEX | 1.2 г | `5d+1(2) pi-` | 0.730303 d6 | `1d-1 cr ex` | `1d-2 cut` |

Осколочный результат до округления: `2 * sqrt(6 / 146) = 0.405442 d6`. Для APEX `0.3 < 8 * 0.05`. Для APHEX используется собственная явно введённая масса ВВ.

## Три кнопки и Follow-up

Адаптер `damage-shot-link` добавляет к существующей карточке GGA две копии штатной кнопки Damage для взрыва и осколков; основная сохраняет имя патрона конкретного выстрела. Каждая кнопка получает собственную формулу из завершённого снимка этого сообщения и проходит через штатные `parselink`, `performAction`, подтверждение броска, DamageChat и transfer GGA. Текущий магазин не читается, патроны не списываются. Нерассчитанный компонент отключён с объяснением. Для закрытых исходных сообщений используется ссылка на источник вместо публикации полного снимка; чтение проверяет текущие права на исходное сообщение.

Дополнительная информация свёрнута по умолчанию. Условие Follow-Up, проникновение, внутренний взрыв, Explosion и обработку DR в Apply Damage выбирает GM. Автоматического ×3, игнорирования DR, отдельного огненного урона, HT/Will/Affliction или дополнительной карточки атаки нет. Incendiary у APHEX показан как информация ведущему.

В существующем макросе `explosion-fragmentation` добавлен локализованный, по умолчанию выключенный Follow-up. При выключении сохраняется прежний механизм. При включении GM подтверждает условия; результат равен `max(1, обычные попадания)`: гарантируется первый слот, уже полученное первое попадание повторно не добавляется, остальные сохраняются. Макрос вызывается существующим API модуля; документы пользовательских макросов и компендий не заменялись.

## Границы

Домашняя модель осколков требует выбранной GM калибровки; универсальной таблицы урона по калибру нет. Реальная масса и допустимость конкретного APEX/APHEX не выводятся из имени оружия. Отмена разрешения ограничивает новые атаки, а завершённые снимки остаются историческим источником Damage. Для других версий GGA сохраняется диагностика контракта; данная живая проверка выполнена только на GGA 0.18.23.

JSON каталогов, файлы GGA/GCS и Actor.system не изменялись. Новая миграция боезапаса не вводилась. Commit, push, merge и rebase не выполнялись.
