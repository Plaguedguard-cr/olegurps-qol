# Targeted Attack при skill default

Исправлена блокировка обычного выстрела по зоне тела при использовании Guns (SMG) по законному default от Guns (Rifle).

## Причина и изменение

Контекст TA строил варианты из изученных Guns персонажа, не получая готовый результат разрешения governing skill. На Module Test это Pistol, Rifle и Shotgun; SMG отсутствовал. Fire Control уже знал требуемый SMG и его default, поэтому отдельного селектора не показывал. Проверка `parseShotOptions` всё равно требовала выбор из старого списка и отменяла весь бросок. Отсутствие подходящей техники превращалось в запрет обычной атаки.

`createRangedTargetedAttackContext` теперь передаёт результат существующего `resolveRangedGoverningSkill` в общий сервис TA. Для автономных режимов тот продолжает использовать `resolveStandaloneSkill`. Специализация требуемого навыка отделена от `sourceName` default; вычислитель навыков и персональная политика TL не изменены.

Из обычной подготовки выстрела и проверки Trademark Move удалён обязательный выбор TA. Без подходящей изученной техники используется исходный Hit Location. Проверка готовности автономного оружия и законности default сохранена. Изученные улучшения не переносятся на неизученный требуемый навык.

При разрешении TA проверяются специализация, зона и явный TL техники/требуемого навыка. Legacy-метаданные источника default не подменяют требуемый навык. Нулевые points не превращают неизученную TA в изученную. Для старой TA без TL улучшение применяется только при однозначном родительском навыке. Расчёт по общему каналу Hit Location заменяет штраф один раз.

Затронуты `targeted-attack-service.js`, `ranged-governing-skill-service.js`, `ammo.js`, `fire-preparation-app.js`; добавлен `tests/targeted-attack-defaults.test.mjs`. Actor.system, GGA/GCS, каталоги, AttackProfileResolver и формулы Damage не изменялись.

## Foundry 14.364 / GGA 0.18.23

Использована временная копия именно исходного Module Test с его настоящими навыками и TA. На копии добавлены автономный H&K MP7A1 из существующего каталога и базовые патроны. До исправления выбор Face завершался предупреждением об отсутствии броска: 0 новых сообщений, магазин 4/4.

После исправления SMG: навык 10 (default −2 за специализацию и −1 за TL), Face −5, Aim +6, эффективный навык 11. Настоящие 3d6 дали 13 (промах) и 9 (попадание). Магазин изменился 4 → 3 → 2, по одному патрону за каждый выстрел. Штатная кнопка GGA Damage на попадании бросила 4d+1, результат 19. Система Actor копии не изменилась.

Оружие из настоящего списка GGA: Izhmash AK-47, явно выбранный Guns/TL9 (Rifle)-13, TA Face-11. Штраф −5 заменён на −2, Aim +6, эффективный навык 17. Настоящий 3d6 дал 15. Штатный Damage 5d+1 дал 22; магазин 2 → 1.

Для SMG переключён другой, пустой магазин. После полной перезагрузки старое сообщение сохранило снимок, навык 10, effectiveSkill 11, политику бросавшего GM и кнопку `D:4.6x30mm Royal Ordnance`. Повторный штатный Damage дал 17 по прежней формуле 4d+1; магазины остались `[2, 0]`. Повторный Damage штатного GGA оружия дал 20 по 5d+1, магазин остался 1. После возврата снаряжённого магазина подготовка SMG после reload снова показала Face −5 и effectiveSkill 11 без требования specialty.

После финального уточнения legacy-пути код повторно загружен в Foundry: SMG по-прежнему не получает TA Rifle; штатная TA Rifle даёт −2; явное требование SMG с источником Rifle не получает чужую TA. Старый snapshot и система копии сохранились.

Временные Actor, Token и 10 сообщений проверки удалены. Исходные 12 Actor, 4 User flags, 6 старых сообщений, политика допусков, язык, выделение токенов и LastActor сохранены. Пакеты LevelDB и посторонние изменения рабочего дерева не очищались.
