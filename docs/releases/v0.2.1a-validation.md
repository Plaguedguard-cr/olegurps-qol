# Проверка OleGURPS QOL v0.2.1a

23 октября 2026 г. Node 22.19.0, Windows. Полный набор тестов не запускался.

## Адресная регрессия

**2037 PASS, 0 FAIL, 0 skipped** в 49 файлах. Проверены новые семейства UT,
HT/UT боеприпасы, Gyroc, Fluid/Vortex, биохимия и Tear Gas, штатное сопротивление,
Damage, ресурсы, UAW/ETC/LP, история и приватность Foundry 14.

Первый прогон выявил 59 сбоев в устаревших тестовых контрактах. Исправлены
синтетические связи каталогов и количество новых идентичностей, дефолты
ChatMessage в адаптере и ожидание сохранения штатной приватности GGA.
Проверки не удалялись и не пропускались. Игровые механики в ходе подготовки
релиза не менялись.

Итог проверен в чистых временных копиях подготовленного Git index:
33 файла — 1543 PASS; оставшиеся 16 файлов — 494 PASS.
Каталоги и неизменяемая аудиторская фикстура сохраняют проверенные LF-байты
через `.gitattributes`; эталонные хеши не менялись. Историческая проверка HT/LT
получила узкую фикстуру с SHA-256 исходного локального аудита вместо зависимости
от полного локального отчёта.

При подготовке релиза новые живые броски не выполнялись; окно Foundry не
разворачивалось. Предыдущие живые проверки описаны в отчётах соответствующих
семейств и [истории выстрелов](../shot-history-performance-optimization-report.md).

## Сборка и статические проверки

- `node --check` для изменённых и новых JS/MJS, строгий UTF-8, JSON и проверка
  повреждения текста; `git diff --check` и `git diff --cached --check`.
- `.github/scripts/validate-release.mjs` с тегом `v0.2.1a` и репозиторием
  `Plaguedguard-cr/olegurps-qol`: версия, manifest, download, runtime и compendium.
- `tools/check-ut-weapons-inventory.mjs`: связи текущего реестра и каталогов.
- Сборка той же командой `git archive`, что в release.yml; проверены CRC,
  полный список и байты каждого из **254 runtime-файлов**, включая новые
  biochemical, Fluid/Vortex, Gyroc, shot-history и chat-message-mode.
- В workflow добавлена проверка полного состава архива. Сохранён существующий
  `export-ignore` для инструментов `scripts/audits`; импортов из них в runtime нет.
- ZIP содержит manifest в корне. Тесты, документация, инструменты разработки,
  PDF, временные файлы и локальные сохранения в установочный ZIP не включены.
  Для compendium используются опубликованные исходные файлы Git; живая LevelDB
  пользователя не изменяется и не попадает в коммит.

Исторические документы и датированные матрицы сохраняют версии своего этапа.
Текущая версия синхронизирована в module.json, README и текущем реестре UT.
Публикацию и загрузку обоих assets необходимо проверить после успешного workflow;
локальная сборка сама по себе не подтверждает доступность GitHub Release.
