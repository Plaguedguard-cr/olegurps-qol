решение проекта; оно не выдаётся за книжное доказательство безопасности конкретного АК.

Оригинал **GURPS Ultra-Tech 2007, с. 141–143** прочитан в BooksCodex:
описания на с. 141, таблица на с. 142 (PDF 143), питание на с. 143.
ID принадлежат модулю; происхождение — `module-owned-source-transcription`,
ревизия `ut-2007-1`. Новые модели имеют статус `definition-only`.

В том же агрегатном тесте было вложенное устаревшее ожидание UT/APHEX.
Текущий итог: 87 связей вместо 85; compatible остаётся **52**, undetermined
становится **10** вместо 6, incompatible — **25** вместо 27. Две новые модели
добавляют два unresolved случая. Ещё два прежних отказа переведены в unresolved
из-за уже отмеченных противоречий UT141/143 у `WJstukbcBFPxQFtJE` и
`WbvkCgoaLuWViWyKK`. Для каждой причины добавлены точные проверки;
автоматических профилей UT/APHEX по-прежнему **0**. Это согласование теста
с существующей UT-DATA, без изменения реализации Ultra-Tech.

Дополнительно первый запуск обнаружил пятый FAIL: проверка локализации выбирала
первый ключ с совпадающим окончанием и сравнивала сообщение `AmmoEffects`
с другим текстом из `AutomaticAmmo`. Тест теперь сначала выбирает точный ключ
`OleGURPS.AmmoEffects.*`; для общих сообщений без такого ключа сохраняется
проверка действующего межпространственного fallback. Наличие переводов в обоих
словарях и точное соответствие русского результата проверяются по-прежнему.
Ни тексты интерфейса, ни словари не изменены.
