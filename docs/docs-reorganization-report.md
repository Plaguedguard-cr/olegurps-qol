## Что находится в архиве

[Манифест](</A:/Program Files/FoundryVTT-R/olegurps-qol-archive/snapshots/2026-10-14-docs-reorganization/manifest.json>) содержит для каждого файла исходный путь, полный путь копии, размер, SHA-256, исходное отслеживание Git, категорию и причину. Дополнительно записаны исходный HEAD, точная контрольная сумма извлечённой фикстуры и 206 исключённых путей индекса.

Архив расположен вне репозитория, вне Foundry Data/modules и вне другого Git-репозитория. Доступ к постоянному каталогу проверен созданием/удалением пробного файла. Это не временный каталог.

Перенесены stage/batch/initial/regression-отчёты, старые итоговые сводки, TAP, диагностические и before/after JSON, скриншоты, индивидуальные источниковые аудиты LT/HT/UT, утверждённая матрица сложных эффектов, исходные доказательства и книга. Простое упоминание в старом отчёте не использовалось как основание оставить файл в docs.

Классификация исходных 267 документов: **9 ACTIVE**, **13 TEST_FIXTURE**, **245 ARCHIVE**. Три ранее удалённых дубликата дополнительно сохранены как **REDUNDANT**. Уникальные материалы не уничтожались. Все 55 исходных неотслеживаемых/игнорируемых документов, включая PDF, сохранены в архиве.

В частности, доступны исходный аудит всех 511 связей, источник HT178, обзор 64 вариантов, F1–F4/P1–P7, HAFLA DATA-задача, Gyrojet/FN 303/Hydra и подробные испытания подписей/производительности. Их исходные Markdown-ссылки продолжают работать внутри сохранённого дерева `snapshot/docs`. Три прежних удалённых TAP восстановлены туда из HEAD, поэтому историческому снимку не требуется искать их в текущем проекте.

Для каждого перенесённого существовавшего файла сначала проверены все копии, затем повторно сверены оригинал/копия непосредственно перед удалением оригинала. Оригиналы не удалялись по предположению, что копирование удалось. Непроверенных или потерянных файлов нет.

## Испытание без архива и книги

Использована отдельная копия текущего рабочего дерева без `.git`, docs/audit, PDF, локального архива, секретов и живых LevelDB packs. Она предназначена для Node-проверок структуры проекта, не является экспортом релиза. В окружении тестов оба `OLEGURPS_ARCHIVE_*` указывали на несуществующие каталоги. Тестовые данные не подставлялись из архива скрыто.

Адресный запуск 29 связанных файлов дал первоначально **948 тестов: 918 PASS / 30 FAIL**. В извлечении старых 12G-данных обнаружены отсутствующие name, standaloneOnly и четыре проверяемых raw-поля. Они добавлены из оригинала с проверенным SHA-256. Повторены только этот изменённый файл и проверки изменённой фикстуры: **33 PASS / 0 FAIL**. Таким образом, по выполненным адресным проверкам закрыты все 22 ошибки извлечения; итоговое покрытие основного запуска — **940 PASS / 8 прежних FAIL**. Полный неизменённый запуск не повторялся ради общего числа.

Все восемь оставшихся случаев отдельно воспроизведены в диагностической копии с **полными проверенными оригинальными JSON**: **0 PASS / 8 FAIL**. Эта диагностика использовала архив явно и не считается испытанием без него. Она подтвердила прежние ошибки и дополнительно выявила недостающий GM.loadingCheckRequired в извлечении: флаг восстановлен из оригинала, затем именно этот сценарий повторён в копии без архива. Он дошёл до той же прежней UI-ошибки unavailable; связанная проверка фикстуры прошла (1 PASS / 1 прежний FAIL). Тем самым ошибки сокращения исправлены, а старый FAIL не скрыт более ранним отказом.

Известный спор F3 проверен отдельно в копии без архива: **0 PASS / 1 прежний FAIL**. Тест и инструкция дыма не изменялись. В сумме незакрыты девять прежних случаев, а не ошибки потерянных документов.

## Как пользоваться архивом и восстановить данные

Проверка целостности всех копий:

```powershell
node tools/verify-document-archive.mjs
```

Историческая копия книги сохранена в архиве:

```text
A:\Program Files\FoundryVTT-R\olegurps-qol-archive\snapshots\2026-10-14-docs-reorganization\docs\GURPS - 4E - High Tech.pdf
```

Для новых проверок правил использовать строго только для чтения
`E:\НРИ\GURPS\BooksCodex` согласно AGENTS.md;
[проверка подключения библиотеки](gurps-library-connection-report.md).
Архивная копия остаётся историческим материалом.

Для другого компьютера скопировать **весь каталог архива**, сохранив snapshot/manifest и относительные пути. Указать его расположение, не меняя язык или настройки Foundry:

```powershell
$env:OLEGURPS_ARCHIVE_ROOT = 'D:\LocalSources\olegurps-qol-archive'
# Для выбора другого конкретного снимка:
$env:OLEGURPS_ARCHIVE_SNAPSHOT = 'D:\LocalSources\olegurps-qol-archive\snapshots\2026-10-14-docs-reorganization'
node tools/verify-document-archive.mjs
```

Манифест содержит старые абсолютные пути для происхождения, но verifier/читатель используют новый корень и исходные относительные пути. Для восстановления конкретного материала копировать `snapshot/<originalPath>` в выбранную локальную папку и проверить указанные размер/SHA-256. Не возвращать сотни исторических отчётов в публичный docs автоматически. Обычные тесты используют закреплённые фикстуры без этих переменных; источниковые инструменты требуют архива, а полноценная сверка правил — также оригинальной книги.

Файлов, которые не удалось безопасно перенести, нет. Препятствий доступа или неподтверждённых копий нет. Незакрытые проблемы ограничены девятью прежними тестовыми расхождениями, перечисленными выше; реорганизация завершена без потери материалов и без публикации книги.
