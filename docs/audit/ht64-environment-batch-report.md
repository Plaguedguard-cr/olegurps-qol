# High-Tech, пакет 4/7 — специальные заряды и среда

Игрок может выбрать подтверждённый WP для Buck HAFLA, 35mm, добавить запас и снарядить контейнер через существующее окно. Это одно готовое сочетание режима и заряда; базовый выбор и выбор WP — два представления одного источника, а не два разных патрона. Для остальных 12 вариантов есть общий проверяемый механизм расчёта и сохранения известных правил, но в текущих активных привязках отсутствуют полные подтверждённые конструкции. Они недоступны для нового снаряжения. Разрешение GM и разрешающая политика не заменяют отсутствующее вещество, дозу, скорость или конструкцию.

Модуль рассчитывает доказанные преобразования Damage, Range, делителя и цены, сохраняет исходные правила и наполнитель в immutable shotSnapshot, использует обычный AmmoService и штатный Damage GGA. Чистые функции рассчитывают ограничения видимости, время разрастания известного облака, продолжительность последствий газов и расписание контактного горения. Эти функции не назначают эффекты участникам сцены, не выполняют сопротивления и не списывают ресурсы.

Согласно последней поправке пользователя систематическая доработка публичных карточек GM и выбор способов применения сложных эффектов перенесены на отдельную задачу после всех семи пакетов. Существующие подсказки и общая секция условий Damage сохранены. Новая подробная публичная инструкция для каждого эффекта сейчас не добавлялась. Известные правила и исходные `chat_hint_ru` сохранены в снимке для последующей доработки. Полной автоматизации газа, облаков, горения или состояний не заявляется.

В настоящем Foundry 14.364 / GGA 0.18.23 проверены выбор WP, запас, снаряжение, штатный бросок через существующий API, основной и осколочный Damage, смена контейнера и reload. **Полный сценарий через окно Fire Control блокирован:** опубликованная запись Buck HAFLA имеет `Acc: null`, а существующий механизм готовности автономного оружия требует Acc. Отсутствующее число не придумано и проверка не обходилась в интерфейсе. Диагностический бросок через API отдельно описан ниже; он не считается успешным прохождением полного UI-сценария.

## Для задачи после семи пакетов

- Устранить нехватку Acc у подтверждённого HAFLA по достоверному источнику либо отдельно определить допустимый интерфейс атаки без Aim; не выдумывать характеристику ради прохождения UI.
- Подключить сохранённые P5-правила к подробным публичным инструкциям GM, учитывая blind/whisper и скрытые сведения наполнителя. Проверить реальные карточки каждого вновь подтверждённого заряда.
- Для дыма определить источниковую область, длительность, участников и влияние на зрение/лазер/радар. Общая геометрия без источника не создаётся.
- Для газов определить экспозицию, защиту органов дыхания, выполнить отдельные сопротивления и применить состояния средствами GGA/GM. Численные сроки вычисляются лишь при известном результате сопротивления; второго независимого движка состояний нет.
- Для illumination/signal и WP выбрать способ отслеживания контакта, горящих осколков и удаления материала. Сейчас расписание вычислимо, но периодический Damage/DX не запускается автоматически.
- Для poison/liquid/poison gas добавить достоверные конструкции с конкретным веществом, дозой и полным описанием; сохранить исходные HP-условия, не обходить существующее ограничение Malf/скорости.

Эти случаи документированы и остаются нерешёнными в соответствии с поправкой. Новые крупные окна, изменения сложных механизмов GGA и автоматизация любой ценой не добавлены.
