# «Добавить оружие»: реализация и проверка

Дата проверки: 9 октября 2026 года. Foundry VTT 14.364, GURPS Game Aid.

Основная форма сохраняет Governing Skill и Weapon Bond. Вспомогательный редактор не дублирует и не сбрасывает выбор навыка; автономное оружие описано в [действующей спецификации](standalone-weapons.md). Исторические визуальные проверки находятся в локальном архиве.

## Изменённые окна и компоненты

- `scripts/tools/ammo.js`: существующая форма добавления/настройки оружия и обновление уже открытых окон Fire Control после сохранения.
- `scripts/tools/weapon-attack-editor.js`: существующий редактор DialogV2 расширен полным поиском каталога, выбором конкретного equipment/mode, Governing Skill и тем же Weapon Bond.
- `scripts/tools/fire-preparation-app.js`: большой селектор Governing Skill заменён компактным отображением используемого навыка и его уровня.
- `scripts/tools/weapon-configuration.js`: черновик существующей формы, её разметка, сравнение характеристик и обработчики выбора. Постоянные настройки остаются в существующем состоянии AmmoService и флаге WeaponCatalogBindingService.
- `scripts/tools/ammo-service.js`: нормализация нового состояния без созданных магазинов. Старые записи продолжают использовать прежнюю нормализацию.
- `styles/olegurps-qol.css`, `lang/en.json`, `lang/ru.json`, `scripts/tools/weapon-localization.js`: компактные стили, переводы и fallback для кэшированного языкового манифеста Foundry.
- `tests/weapon-configuration.test.mjs`: 30 адресных тестов. В существующем тесте локализации Developer проверка ограничена его собственными ключами.

Оба диалога используют существующий DialogV2, основанный на ApplicationV2. Отдельной системы оружия или второго редактора нет.

## Итоговая форма

Поля идут вертикально: Дистанционная атака GGA → Соответствие каталогу с карандашом справа → Тип боеприпаса → Governing Skill → Weapon Bond → Сохранить.

Ширина основной формы сохранена: 720 px. Редактор расширен с 480 до 520 px для поиска. Длинные строки сокращаются средствами select; полное название доступно в title. Под соответствием показаны статус и небольшое сравнение: зелёный знак `=` для совпадений, красный `≠` для различий, фактическое значение рядом с каталожным в скобках. Красное отличие не блокирует сохранение.

Убраны количество патронов, ёмкость, количество магазинов и заполнение магазинов. Новых полей количества боезапаса нет.

## Каталог и подтверждение

Кандидаты и их порядок берутся из WeaponCatalogBindingService. Только его статус `suggested` даёт автоматический выбор. Это предложение явно подписано; Save подтверждает показанную модель через существующий сервис.

При неоднозначности выбор остаётся пустым и показано «Требуется проверка». Save без явного выбора не создаёт подтверждённую привязку. Существующая подтверждённая модель имеет приоритет. Изменение режима или идентичности после импорта использует сервисный статус проверки; другой GGA-режим молча не присваивается старому оружию.

Полный поиск в существующем редакторе ищет по названию, источнику, режиму, equipment_id и weapon_mode_id. Показываются первые 100 результатов с возможностью уточнить запрос; текущая модель сохраняется среди вариантов. Выбор каталога не меняет GGA-атаку или её характеристики.

Каталог, параметры, навык и Weapon Bond изменяются в черновике. Закрытие редактора отменяет его изменения. Save редактора возвращает их основной форме; закрытие основной формы без Save отменяет весь черновик. Повторное открытие и сохранение редактора не теряет ранее подготовленные числовые изменения. Каталожный выбор без изменения параметров не создаёт числовой override.

## Сохранность данных

Боеприпасы берутся только из подтверждённой совместимости `ammo-item`/`ammo-family`. Native-связь имеет приоритет; variants и undetermined не предлагаются. Старый текстовый тип и подтверждённый выбор сохраняются. Несоответствующий новой модели сохранённый боеприпас отображается с требованием проверки. Явный нейтральный выбор остаётся нейтральным при повторном открытии.

Навыки перечисляются и разрешаются существующим Ranged Governing Skill service. Предложение учитывает реальную специальность и доступные данные GGA/каталога. TL оружия не фильтрует навыки, уровень берётся из GGA. Сохранённые binding и числовые overrides имеют приоритет; исчезнувший навык виден как требующий проверки.

Weapon Bond использует существующее поле `weapon.weaponBond` и существующий расчёт. Сохранённый флаг не стирается при исчезновении перка. Новый канал или дополнительный бонус не вводился; сохранены ранее находившиеся в рабочем дереве исправления Weapon Bond.

Сохранение старого оружия не редактирует totalAmmo, capacity, magazines или loadedIndex. Для нового оружия хранится `ammoUnconfigured: true`, totalAmmo=0, capacity=0, magazines=[], loadedIndex=-1. Нормализация не создаёт пустой магазин; действия, которым нужен магазин, недоступны. Новой механики снаряжения и миграции старых записей нет.
