# Персональная политика TL для навыков оружия

Настройки → OleGURPS QOL → «Персональные настройки оружия» → «Настроить»: галочка «Игнорировать разницу TL для навыков оружия». В EN используется «Ignore weapon skill TL differences». Раздел доступен игрокам и GM, использует ApplicationV2. По умолчанию галочка выключена.

Значение хранится на сервере в `User.flags.olegurps-qol.ignoreWeaponSkillTLDifferences`, сохраняется за пользователем после reload и смены браузера. Общая настройка мира и браузерное localStorage не используются. Сохранение формы меняет только flags выполняющего действие пользователя. Открытые помощники и карточки Fire Control обновляют предпросмотр.

Существующий `resolveStandaloneSkill` получает политику пользователя. Только после проверки изученного источника и направленного каталожного default штраф TL заменяется нулём, если семейство исходного и требуемого оружейного навыка совпадает. Штраф самого default/специализации остаётся. Между разными семействами навыков TL-штраф сохраняется. Неизвестный TL, отсутствующее правило, default от неизученного навыка и цепочка defaults не становятся допустимыми. Default от атрибута и Rule of 20 не меняются. Другие модификаторы и правила улучшенных техник не отменяются.

Результат навыка содержит `tlPolicy` с версией, ID выполняющего бросок пользователя и значением настройки. Кандидат default содержит `defaultPenalty`, применённый `tlPenalty` и исходный `standardTLPenalty`. Всё сохраняется существующим pipeline в `shotSnapshot.mode.standaloneRef.governingSkill` и копии режима профиля. Исторический Damage и показ сообщения используют этот снимок, без повторного чтения предпочтений зрителя. Если GM бросает за игрока, применяется выбор GM, а не владельца Actor.

Каталоги, исходные навыки Actor, GGA/GCS и формулы Damage не меняются.
